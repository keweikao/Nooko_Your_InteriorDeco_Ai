> **版本**: 1.0

> **用途**: 作為「報價防呆守衛」的核心知識基礎，供 AI 引擎比對報價單使用

## 一、標準施工順序（工序流程）

### 全室裝修標準流程

```
保護工程 → 拆除工程 → 水電工程（配管線）→ 泥作工程（砌牆/防水/整平）
→ 防水工程（試水測試）→ 木作工程（天花板/隔間/造型）
→ 油漆工程（批土/底漆/面漆）→ 地板工程
→ 系統櫃/廚具安裝 → 空調設備安裝 → 門窗工程
→ 衛浴設備安裝 → 燈具/五金安裝 → 清潔工程（粗清→細清）
```

### 依屋況分類的施工順序

| 屋況 | 施工順序特點 |
|------|------------|
| **新成屋** | 無需拆除，從保護→水電→泥作開始 |
| **毛胚屋** | 從水電管線配置開始，需全面泥作 |
| **中古屋（10-20年）** | 需局部拆除，重點在水電更新、防水重做 |
| **老屋翻新（20年+）** | 全面拆除→結構補強→水電全面更新→全室重做 |

### 工序間的硬性先後關係

```
拆除 ──→ 水電配管 ──→ 泥作封管 ──→ 防水 ──→ 貼磚
                 ↘                    ↗
                  泥作砌牆 ──→ 粉光 ──→ 防水（浴室）

木作天花板 ──→ 油漆批土 ──→ 油漆面漆 ──→ 燈具安裝

地面整平 ──→ 地板鋪設 ──→ 收邊/踢腳板

系統櫃丈量 ──→（工廠製作 2-4 週）──→ 現場安裝
```

## 三、工序相依規則（If-Then Rules）

### 關卡 1：工序連動（漏項檢查）

| 如果報價有... | 則必須有... | 嚴重度 | 說明 |

| 現場條件 | 報價含有... | 必須另加... | 嚴重度 |

### 關卡 3：數量合理性檢查

| 工項 | 合理比例/公式 | 異常判定 |
|------|-------------|---------|
| **油漆面積** | 地坪 × 2.5 ~ 4.0（含牆面+天花） | < 2.0x 或 > 5.0x 異常 |
| **磁磚面積（地）** | ≈ 實際鋪設面積 × 1.05~1.10（含損耗） | 損耗率 > 15% 異常 |
| **磁磚面積（壁）** | 浴室：(周長 × 高度) × 1.08 | - |
| **電線迴路數** | 基本 6~8 迴路 + 廚房 2~3 + 冷氣每台 1 | 20 坪以上少於 8 迴路異常 |

## 六、報價單常見格式（欄位結構）

### 典型報價單欄位

```
| 項次 | 工程項目 | 規格說明 | 單位 | 數量 | 單價 | 複價(小計) | 備註 |
```

### 常見分類方式

報價單通常按工種分大類，每個大類下列出細項：

```
一、拆除工程
  1. 天花板拆除          坪    12    1,200    14,400
  2. 地磚拆除            坪    25    1,500    37,500
  3. 垃圾清運            車     3    8,000    24,000
                                    小計     75,900
二、水電工程
  1. 全室重新配線        式     1   120,000   120,000
  2. 開關插座增設        個    15    2,000    30,000
  ...                               小計    150,000

（各工種依此類推）

                                    總計    XXX,XXX
                                    稅金（5%）XX,XXX
                                    合計    XXX,XXX
```

### 常見計價單位

| 單位 | 使用時機 |
|------|---------|
| 坪 | 面積類：油漆、地板、天花板、拆除 |
| 才 | 門窗玻璃（1才 = 30cm × 30cm） |
| 尺 | 線性：系統櫃、踢腳板、窗簾盒 |
| 式 | 整體包含：全室水電、防水、清潔 |
| 個/組 | 單品：插座、洗洞、衛浴設備 |
| 台 | 設備：冷氣、抽風機 |
| 樘 | 門窗：一扇門或一扇窗 |
| 車 | 垃圾清運 |
| 米 | 管線類：冷媒管、排水管 |
| 迴路 | 電線迴路 |

## 七、報價單常見問題（紅旗警示）

### 格式面紅旗

| 警示 | 說明 | 風險 |
|------|------|------|
| 大量「一式」計價 | 無法驗證數量合理性 | 🔴 高 |
| 無規格說明 | 材料品質無從驗證 | 🔴 高 |
| 無單價只有總價 | 無法分辨工料比 | 🟡 中 |
| 工種分類混亂 | 不同工種混在一起 | 🟡 中 |
| 無備註/施工說明 | 施工範圍模糊 | 🟡 中 |

### 內容面紅旗

| 警示 | 說明 | 風險 |
|------|------|------|
| 報價金額過低 | 可能故意壓低，後續追加 | 🔴 高 |
| 工項過少（相對工程規模） | 可能大量漏項 | 🔴 高 |
| 缺少垃圾清運 | 幾乎所有工程都需要 | 🟡 中 |
| 缺少保護工程（大樓） | 管委會可能罰款 | 🟡 中 |
| 浴室翻新但無防水 | 致命漏項 | 🔴 高 |
| 有拆除但無整平 | 後續工程基礎問題 | 🔴 高 |
